**오케스트레이터 자체 실수**: 복구 스크립트가 재구성 원본을 임시 폴더가 아닌 실제 경로에 써서 5개 파일이 약 5분간 원본 상태로 바뀌었다. 사고 직전에 떠둔 작업 트리 백업(`tmp/backups/worktree-20261126-1532.tar.gz`)에서 바로 복원 — 잃은 것 없음.

**재발 방지**: 하네스 규약 **v4.2.3** — 병렬 fan-out 위임 제약에 "워크트리 되돌림 금지"(git 명령으로 워크트리 파일을 쓰거나 되돌리지 않는다·수정은 Edit/Write 도구만·미커밋 배치가 있으면 fan-out 전 백업) 추가, 전역·프로젝트 스킬·사본 동기화. 이후 지시서에는 명시했고 FIX3·테스터는 git 쓰기 없이 진행.

**검증**: 전체 테스트 수가 1,885 → 1,927로 증가(손실로 줄지 않음), 전체 게이트·시스템 테스트 통과.
