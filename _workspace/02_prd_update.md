### PLAN-9 요지

- 관리자 콘솔에서 결제 완료 주문을 환불하면 **포트원 결제 취소 API로 즉시 전액 환불**(부분 취소·예약 취소 없음).
- 상품별 되돌리기:
  - Plus 월 구독 주문 → 회원 구독 **즉시 Free**(남은 기간과 무관·빌링키·주기 삭제 — 재구독 시 카드 재등록).
  - 수금 패스 주문 → 회원의 유효한 패스에서 **구매 수량(10건)만큼 차감**(만료 임박순) — 모자라면 0에서 종료.
  - 내용증명·전자세금계산서 주문 → 환불만. **이미 생성·발행된 것은 건드리지 않는다**(세금계산서 취소 요청 없음).
- 확정 절차: PG 취소 요청 → PG 서버 **재조회로 전액 취소 확인**(결제 완료 사실 + 전액 취소 **모두** 확인 —
  하나라도 미확인이면 로컬 변경 없이 실패) → 주문 `status: cancelled`·`refunded_at`·`refund_reason` 기록 →
  상품 되돌리기 → 감사 로그.
- 포트원 콘솔에서 먼저 환불한 건도 같은 버튼으로 정산을 완료한다(재동기화). 웹훅은 변경 없이 멱등.
- 환불된 건별 상품은 회원이 앱에서 다시 내려받을 수 없다(이미 받은 파일·발행된 세금계산서는 그대로).
- 운영 절차: 환불은 반드시 관리자 콘솔에서. 회원에게 따로 알리지 않는다(후속 과제).

### ADMIN-11 요지

- 주문 상세의 "결제 취소(환불) 실행" 버튼 — 사유 필수, 제출 전 확인 대화창에 **실행 효과**(환불 금액·구독 즉시
  Free·수금 패스 10건 차감) 표시.
- **실행은 최고 관리자(owner)만** — staff는 주문 조회만 가능하고 실행 폼이 보이지 않는다(직접 요청은 거부 +
  감사 기록 — ADMIN-1 owner 가드 선례).
- 실행 결과(실행자·일시·금액·사유)를 주문 상세에 표시하고 감사 로그(ADMIN-2)에 기록.
- 포트원 콘솔에서 먼저 취소돼 정산이 안 된 주문(`cancelled`인데 `refunded_at` 없음)에는 "정산을 완료하세요" 안내.
  결제 완료 적이 없는 주문(pending·failed·`paid_at` 없음)에는 버튼을 노출하지 않는다.
