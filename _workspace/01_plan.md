# 01_plan.md — 랜딩 페이지 루트 화면 (표면 ① 최소 골격)

- **일자**: 2026-10-08
- **pipelineType**: Full (Phase 0→1→✋→2→3→4→5→7→8→9)
- **도메인**: F-SURF / F-LP / F-DESIGN (PRD §7)
- **비고**: 하네스 E2E 검증(A3) 겸용 — 첫 파이프라인 실행

## 작업 범위

표면 ① 랜딩(`/`)의 **최소 골격**: 루트 라우트 + 컨트롤러 + LP-1 히어로 섹션 1개.
LP-2~LP-13 (페인 공감, 작동 방식, 기능, 문구 공개, 포지셔닝, 요금제, FAQ, 후기, 푸터, 콘텐츠 허브)은 **후속 작업으로 제외** — 이번은 파이프라인 검증 겸 표면 ① 오픈.

## 관련 Rule ID

| Rule | 요구사항 | 이번 구현 |
|:---|:---|:---|
| SURF-1 | 표면 ① = 메인 도메인 `/` | root 라우트 신규 정의 |
| SURF-3 | 표면 ①은 색인 **허용** (noindex 금지) | noindex 메타 넣지 않음 |
| SURF-4 | ①→② 진입은 소셜 로그인 CTA 단일 진입점 | CTA 렌더 단, F-AUTH 전이라 링크 비활성(연결은 F-AUTH 시점) |
| SURF-6 | 표면 ① 경량 렌더링 | 앱 JS 의존 없는 정적 ERB |
| LP-1 | 헤드라인 "말하기 어려운 '돈 다오', 받을돈이 대신합니다"(Q6 확정), 서브카피=수금 루프 한 문장, 주 CTA "카카오로 시작하기 — 무료 · 카드등록 없음 · 3분", 보조 CTA "작동 방식 보기" | 히어로 전체 반영 |
| LP-12 | 마케팅 문구 P1~P5 준칙, 확정 보장·압박 표현 금지 | 문구는 PRD 확정문만 사용 |
| DESIGN-1/2/3 | 온기×격식, 크림·아이보리 배경 + 딥 그린 액센트, Pretendard 국문 우선 | Tailwind 클래스로 기본 톤만 |
