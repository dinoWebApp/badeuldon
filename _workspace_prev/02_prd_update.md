### TAX-3 요지

- 과세 유형이 간이과세·면세사업자인 사용자는 전자세금계산서를 발급할 수 없다(영구).
- **발행만 차단**: 과세 유형 선택·사업자 정보 저장(바로빌 회원 등록에 사용)·기존 발행 내역 조회·취소는 허용.
- 차단 4지점: 청구서 상세 패널 / 발행 화면 진입(new·create) / **주문 생성(결제 전)** / 발행 서비스 가드.
- 법적 근거: 시행령 §70 — 검색 자료 기준(법령 원문 직접 대조는 못함).
- 법적 예외(§64조의2 — 매출 규모가 큰 간이과세자의 발급 의무, 10% 과세)는 **미지원**, 안내로만 고지.

### TAX-4 요지

- 환경 변수 `TAX_INVOICE_ENABLED`, 기본값 꺼짐(fail-closed).
- 꺼짐: 사이드바 메뉴 비노출 / 청구서 상세 패널 "준비 중" / 발행·설정 화면 직접 접속 차단 / **기존 주문 조회·취소는 허용**.
- 켜는 조건: 바로빌 운영 준비 완료. 랜딩은 스위치와 연동하지 않는다(런칭 전 켜기 전제). 운영 안정 후 걷는다.

## 리뷰 반영 보완 (Phase 6 앞 — 2026-11-24, `_workspace/05_review.md` 기준)

리뷰(CHANGES_REQUESTED — BLOCKER 0·CRITICAL 2·WARNING 5)의 판단을 오케스트레이터가 검토해 전부 채택했다. PRD은 같은 버전(v0.46) 안에서 다듬었다.

| 근거 | PRD 변경 | 내용 |
|:---|:---|:---|
| C-1 | TAX-3 ② | 발행 화면 진입(new·create)이 막히면 **청구서 상세로 되돌린다** — 발행 화면으로 되돌리면 결제 버튼이 남은 막다른 길 |
| C-2 | TAX-3·TAX-4 ④ | **미결제(pending) 주문**의 상세 화면이 결제 화면이기도 하다 — 부적격·꺼짐이면 결제 버튼 대신 안내. ④의 허용 대상을 "결제 완료(paid) 주문"으로 한정. 끈 채로 배포할 때 pending 주문 실패 처리 절차 추가 |
| W-1 | TAX-4 ② | 패널 판정 우선순위에 paid_pending을 꺼짐·자격 없음 **위**로 — 돈을 낸 사용자가 주문 확인 링크를 잃지 않게 |
| W-3 | TAX-3 | 발행 설정 화면은 부적격 사용자를 인증서 등록 다음 단계로 이끌지 않는다 |
| W-4·R-2 | TAX-3 | 안내 문구를 **서비스 기준**으로 — "받을돈에서는 … 발급을 지원하지 않습니다"(법적 단정 회피). 기존 "세무 자문 아님" 고지는 그대로 유지(요구 문구를 모든 플래시에 넣으라는 뜻이 아니었음을 명시) |

### 확인 요청 3건에 대한 오케스트레이터 판정

- **R-1(운영의 pending 세금계산서 주문)** — 운영 DB 읽기 전용 조회: 세금계산서 주문 0건·발행 기록 0건·사용자 9명 전원 일반과세. **현재 노출 0건.** C-2 수정은 여전히 채택 — 나중에 스위치를 긴급으로 끄는 상황에는 pending 주문이 있을 수 있다.
- **R-2("세무 자문 아님" 포함 범위)** — 기존 고지(TAX-1 ⑥) 유지가 의도였다. PRD 문언을 명확히 했다(코드 변경 없음).
- **R-3(법령 원문 대조)** — Reviewer도 대조하지 못했다. 이번 작업은 원문에 의존하지 않도록 안내 문구를 서비스 기준으로 바꿔 리스크를 줄인다. 조 번호·예외 요건·시행일의 확인은 사용자의 세무 확인 몫으로 최종 보고에 남긴다.

### 채택한 경과 관찰(리뷰 "수정 요구 아님" 항목 중)

- `IssueService::TAX_TYPE_BY_USER`는 `general`만 남긴다(가드를 실수로 건너뛰어도 발행이 되지 않는 구조).
- enum 주석(간이과세→영세 매핑 설명) 정정, `create` 액션 줄 수(10줄 기준) 해소, 오타("검증 사알").

### 후속 과제로 넘기는 것(이번 범위 밖 — 최종 보고에 기재)

- 과세 유형 기본값이 일반과세라, 간이과세자가 발행 설정에서 기본값을 그대로 두면 일반과세로 발행된다(발행 설정 저장 시 명시 확인을 요구하는 방안 — PRD 설계 영역).
- 법적 예외(§64조의2) 지원 여부와 기준 금액 확인.
