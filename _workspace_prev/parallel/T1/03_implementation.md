## 3. 자가 검증 결과

- **ERB 구조 검증**: 3파일 모두 `<%`/`%>` 마커 수 HEAD와 완전 동일(terms 12/12·privacy 10/10·refund 3/3) — 모든 변경이 순수 HTML/텍스트, ERB 스크립틀릿 추가·삭제·수정 없음. diff 전수 육안 검증 완료.
  - 참고: Rails 부트 금지로 인한 렌더 테스트 생략 외에 표준 라이브러리 ERB/Erubi 단독 컴파일 체크를 시도했으나, 기존 목차의 `<%= link_to ... do %>` 블록 형태는 Rails의 ActionView 전용 Erubi 핸들러 설정이 필요해 단독 재현 불가 — 실패 지점은 전부 HEAD 기존(운영 중 정상 렌더 중인) 코드이며 작업본 변경과 무관. 마커 수 동일성 + 순수 HTML 변경이라는 사실로 구조 안전성 대신 확보.
- **RuboCop**: 해당 3파일 실행 — 결과는 ERB를 Ruby로 파싱하는 artifact(HEAD 기준선과 동일 조건)로 의미 있는 신호 없음. HTML/ERB는 omakase 린트 대상 외.
- **가격 정합성**: 5,000원·300원·9,900원·20% 모두 PRD(Q5·Q21·Q24) 및 코드 상수와 대조 확인. "부가세 포함" 표기는 PRD에 명시된 구독/패스에만 사용하고 신규 건당 요금에는 기재하지 않음 — 제7조 말미 "요금은 부가세 포함 금액" 포괄 조항이 적용.

## 4. 법무 검토 필요 문구 목록 (Reviewer/운영 인계)

일반 SaaS 양식 수준으로 작성했으며, 사용자의 별도 법률 검토 전제. 아래는 특히 검토 권장 문구:

1. **terms 제7조 5항 "발행 취소 시에도 수수료가 과금됩니다"** — TAX-1 취소 과금 전제(사용자 확정)의 직접 표기. 소비자 관점 명시성 요건(전자상거래법 표시·광고법) 관점에서 취소 과금의 고지 방식 검토 권장.
2. **terms 제7조 4항 "결제가 완료된 건에 한하여 양식 다운로드가 제공됩니다"** — LEGAL-2 결제 후 활성화 정책의 약관화 문구.
3. **terms 제7조 6항 추천 코드 20% 할인 문구** — 할인 대상(Plus 첫 결제 1회)·적용 시점(가입 시 입력분) 문언의 확정. PRD SALES-4의 "1회 전용 쿠폰 자동 생성" 메커니즘과 문언 정합성.
4. **privacy 제1조 휴대폰 번호(필수) 항** — 수집·이용 목적 열거(가입 인증·서비스 알림·유일성 검증)가 개인정보보호법 제15조 고지 요건을 충족하는지. "번호 유일성 검증"이 독립 목적으로 적절한지.
5. **privacy 제4조 바로빌 항 "공동인증서는 바로빌 서버에 보관되며 회사는 보관하지 않습니다"** — 인증서 위탁 보관의 고지 방식(TAX-1 구현의 인증서 위탁 동의 고지 요건과 정합). 제5조 위탁 항과의 이중 기재 관계(제공 vs 위탁 구분).
6. **refund 제1절 부가서비스 환불 불가 항** — "생성·발행(이용)이 완료된 후"의 정의(다운로드 완료 시점 vs 발행 요청 접수 시점) 문언 확정 필요. 현재는 서비스 특성상 즉시 이용 개시로 서술했음.
7. **개정일 표기 방식 불일치**(의도된 선택) — privacy는 공고·시행일을 11-20으로 갱신, terms/refund는 원 시행일 유지 + 부칙 개정일 병기. 문서군 간 표기 방식 통일 여부는 법무 검토에 맡김. 약관 중요 변경 시 전자상거래법상 30일 전 공지 요건과 실제 시행일(11-20 당일 개정·시행) 정합은 운영 판단 사항.

## 5. 범위 외 관찰 (오케스트레이터 참고 — 수정하지 않음)

- terms 제4조(회원가입)는 "이메일과 비밀번호로 계정을 만들고"로만 서술 — AUTH-9 휴대폰 인증 필수화(2026-11-19)가 약관 제4조에 미반영. 본 태스크 지시 범위(제7조·세금계산서·수정일) 밖이므로 건드리지 않음. 후속 갱신 대상으로 기록 요청.

## 법무 검토 7건 처리(2026-11-20)

§4 법무 검토 7건 + §5 관찰 1건(terms 제4조 AUTH-9)을 법률 자문이 아닌 **일반 SaaS 표준 관행으로 정합화**. 3종 뷰 파일만 순수 텍스트/HTML 수정, ERB 스크립틀릿 불변, 테스트·PRD/AGENTS 미수정, 커밋 없음.

**1. 취소 과금 고지(terms 제7조 5항) — 표시·광고 명시성**
- 확정 문구: "전자세금계산서 발행 수수료는 건당 300원이며, 발행 취소 시에도 발행 처리 수수료는 환불되지 않습니다. 본 취소 과금 사항은 결제 전 안내 및 발행 전 확인 화면에서 재고지되며, 발행 전 확인 미리보기로 내용을 점검할 수 있습니다."
- 근거: TAX-1 취소 과금 전제(사용자 확정) 유지 + 과금 사실을 '결제 전 안내·발행 전 확인 화면'의 재고지 체계와 연결해 명시성 확보. "수수료가 과금됩니다"(부과 관점·모호) → "환불되지 않습니다"(소비자 관점·명확)로 전환.

**2. 결제 완료 후 활성화(terms 제7조 4항) — LEGAL-2 정합**
- 확정 문구: "...건별로 결제합니다. 결제 완료 시점에 즉시 이용(PDF 다운로드)이 가능하고, 결제가 완료된 건에 한하여 양식 다운로드가 제공됩니다. 미결제 상태의 건은 워터마크가 표시된 미리보기만 제공됩니다."
- 근거: 활성화 시점(결제 완료 즉시)과 미결제 시 제공 범위(워터마크 미리보기 한정)를 대비 명시해 소비자 오해 차단. F-LEGAL 구현(미결제 워터마크 미리보기)과 문언 1:1 정합.

**3. 추천 20% 할인(terms 제7조 6항) — SALES-4 메커니즘 정합**
- 확정 문구: "Plus 구독 첫 결제 1회에 한하여 20% 할인이 적용되며, 이후 결제부터는 정상 가격이 적용됩니다. 할인은 가입 시 추천 코드를 입력한 경우에만 적용됩니다."
- 근거: 할인 대상(Plus 첫 결제 1회)·적용 조건(가입 시 코드 입력분 한정)·이후 가격(정상가) 3요소를 분리 명시 — "1회 전용 쿠폰 자동 생성" 구현 메커니즘과 문언 정합.
