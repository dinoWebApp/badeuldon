# 받을돈 비즈니스 규칙 참조

## 이 스킬의 목적

구현·리뷰·테스트의 모든 판단 기준이 되는 비즈니스 규칙을 Rule ID와 함께 제공한다. **단일 소스는 `PRD.md`(§5 제품 원칙, §6 기능 명세, §7 표면 구조)이며, 이 스킬은 빠른 참조용 색인이다** — 전문은 PRD를 읽는다. 규칙을 의심하면 PRD 원문이 우선.

## 제품 원칙 (P1~P5) — 모든 기능 판단의 상위 기준

| ID | 원칙 | 구현 함의 |
|:---|:---|:---|
| P1 | 관계 보존 최우선 | 채무자가 보는 모든 문구·톤 검증 필수. 문구 톤 가이드 위반은 CRITICAL |
| P2 | 미워지는 역할의 위임 | 발신자는 항상 서비스('받을돈'). U1 개인 번호·이름 노출 금지(REM-1) |
| P3 | 채무자 무가입 | U2 화면(/b/*)에 가입·설치·로그인·개인정보 입력 요구 금지(PROMISE-2) |
| P4 | 모든 발신은 기록 | 발송·열람·응답·약속 이력은 영구 기록, 사용자 임의 삭제 불가(REM-6) |
| P5 | 규제 경계 내 | 채권 수임·추심·신용정보 조회 코드 금지. "추심 아님" 고지(VIEW-5) |

## 도메인별 핵심 규칙 (Rule ID)

### 계정·인증 (AUTH)
- **AUTH-1**: U1 로그인은 소셜(카카오/네이버/구글)만 — 이메일/비밀번호 방식 구현 금지
- **AUTH-7**: 관리자는 전용 계정(이메일+비밀번호) + 2FA(TOTP) 필수, U1과 완전 분리 (7.1~7.6 안전장치 전부)

### 청구서 (INV)
- **INV-3**: 만기일 기본값 = 발행일 + 30일 (7/14/30/60 설정 가능)
- **INV-4**: 상태 전이 `초안→발행→(미열람|열람)→(연체|약속대기)→(부분입금)→수금완료` + `무효` — enum·전이 검증의 기준
- **INV-5**: 발행 후 본문 수정 불가 — 수정은 무효 처리 후 재발행(링크 토큰 갱신)
- **INV-6**: 무효 처리 → 링크 즉시 폐기 + 시퀀스 즉시 중단 (채무자 별도 고지 없음)

### 공유 링크·열람 (SHARE)
- **SHARE-1**: 추측 불가 고유 토큰 URL (충분한 엔트로피 — SEC-1)
- **SHARE-2**: 유효기간 만기일 후 60일(기본), 수동 폐기·재발급 가능
- **SHARE-4**: 최초 열람 시 U1 알림 지연 60초 이내 (PERF-1)

### 리마인더 시퀀스 (REM) — 제품의 심장
- **REM-1**: 발신자 = 서비스 명의 카카오채널 '받을돈'
- **REM-2**: 기본 시퀀스 D-1(예고)→D+1(확인)→D+7(재요청)→D+14(최종). D+14 문구에 법적 조치/내용증명 언급 금지(Q2)
- **REM-3**: 발송 시간 평일 09:00~18:00 고정 — 야간·주일 발송 해제 불가
- **REM-4**: 문구는 열람 여부·약속·부분입금 상태로 분기
- **REM-10**: 발송은 핵클 메시지 API 단일 채널(알림톡+SMS 대체 통합)
- **REM-11**: 연체 단계 발송 당일 아침 U1 사전 통보 + 당일 취소 창
- **REM-12 / PLAN-3**: 시퀀스는 D+14 자동 종결, 청구 건당 발송 상한 5통(대체 SMS 포함) — 하드리밋

### 응답·약속 수집 (PROMISE)
- **PROMISE-2**: 응답은 어떤 가입·개인정보 입력 없이 (링크 세션에서만 기록)
- **PROMISE-3**: 약속 등록 → 시퀀스 중단 → 약속일 D-1 리마인드 1회 → 도과 미입금 시 D+1 재요청 1회
- **PROMISE-7**: 채무자 "이미 입금했어요" 회신은 **시퀀스 일시정지 + U1 알림만** — 수금 마감 상태 변경은 U1 확인으로만(허위 회신 방지)

### 입금 처리 (PAY)
- **PAY-1**: 원클릭 마감(입금일 자동 기록), **PAY-2**: 부분입금 → 잔액 재계산 후 시퀀스 잔액 기준 계속
- **PAY-5 / PLAN-8**: 계좌조회 자동 입금확인 **구현 금지** (비목표 11 — 재검토 조건 전까지)

### 구독·과금 (PLAN)
- **PLAN-1**: Free = 월 청구 3건 + 거래처 5개, 자동 발송 없음(REM-8: 수동 발송 버튼만)
- **PLAN-2**: Plus 9,900원/월, 첫 14일 무료 체험
- **PLAN-5**: 토스페이먼츠 — 구독=BILLING 정기결제, 건당=단건, 상태 변경은 웹훅으로만 반영

### 채무자 뷰어 (VIEW)
- **VIEW-1**: 비로그인 모바일 웹, 카카오톡 인앱 브라우저 완전 동작 필수(QA 항목)
- **VIEW-5**: 하단 고지 "본 서비스는 채권 추심 업무를 수행하지 않습니다" 필수
- **VIEW-8 / SURF-2**: 뷰어 표시 요소 화이트리스트 — 청구 내용·응답 액션·PDF·고지문만. 내비·마케팅·가입 유도 금지

### 데이터·보안·비기능 (SEC/PERF/TIME)
- **SEC-5**: 동일 청구·동일 단계 발송은 정확히 1회(멱등성) — 발송 로직 중복 실행 방지 필수
- **PERF-2**: 뷰어 최초 화면 2초 이내 · **TIME-1**: 모든 일정·발송 기준 KST 고정

### 표면 구조 (SURF)
- **SURF-1**: 단일 도메인 — `/`(랜딩), `/app`(대시보드), `/b/{토큰}`(뷰어), `/admin`(관리자)
- **SURF-3**: `/app`, `/b/*`, `/admin` noindex + robots 차단
- **SURF-4**: ③→① 링크 금지, ①→② 진입은 소셜 로그인 CTA 단일

## 외부 서비스 의존성 (PRD §6.19)

| 기능 | 서비스 | 비고 |
|:---|:---|:---|
| 알림톡·SMS | 핵클 메시지 API (`message-api.hackle.io`) | 선불 크레딧제 — 잔액 모니터링(ADMIN-5) |
| 결제 | 토스페이먼츠 코어 API | 웹훅 수신 |
| 소셜 로그인 | 카카오·네이버·구글 | |
| 전자세금계산서 | 팝빌(권고) | TAX-1 |

## Rule ID 운영 규칙

- 형식 `{접두어}-{번호}`, PRD 추가 시 기존 마지막 번호 + 1, **폐기 ID 결번 처리(재사용 금지)**
- 하나의 Rule ID = 하나의 검증 가능한 규칙
- 코드 커밋 메시지·테스트·리뷰 지적은 Rule ID를 참조 키로 인용
